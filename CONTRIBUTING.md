# Contributing

Thanks for contributing to the Beatmatcher / DJ App.

## Quick start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the app locally:
   ```bash
   npm run dev
   ```
3. Build before submitting changes:
   ```bash
   npm run build
   ```

## Pull request checklist

- Keep changes focused and small.
- Update docs when behavior or setup changes.
- Ensure `npm run test` succeeds before opening a PR.
- Ensure `npm run build` succeeds before opening a PR.
- Prefer `npm run check` for one-command verification before opening a PR.
